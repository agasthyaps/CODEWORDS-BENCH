# Codewords Bench

Codewords Bench evaluates language-model agents in Codenames, Decrypto, and Hanabi under humanlike game-table conditions.

The benchmark is designed to observe how agents play, not to engineer a harness that maximizes game score. Saved artifacts distinguish normal game outcome from benchmark-performance penalties such as parse failures, repair prompts, fallback actions, invalid moves, and moderator corrections.

See [BENCHMARK_PROTOCOL.md](BENCHMARK_PROTOCOL.md) for the benchmark conditions, seed policy, model-matrix design, and reproducibility manifest requirements.
